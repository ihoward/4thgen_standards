# FGC-00001: LLM Accessibility Practice Group

**Status:** Proposed
**Submitted:** 2026-05-15
**Author:** Ian Howard, atypical
**Type:** New practices + new taxonomy domain (LLM Accessibility)

---

## Summary

This contribution adds five practices that together constitute the LLM Accessibility domain of fourth generation standards. The practices operationalise the "LLM-accessible" property already listed in the 4GS definition of fourth generation, for which no formal practices previously existed.

The practices were derived from two production implementations:

- **XframeworkID** (`xframework.id`) — an open registry of labelled bond disclosure documents. XframeworkID shipped `/llms.txt`, `/llms-full.txt`, and an MCP server (`xframework-mcp`). First-hand observation confirmed that structured LLM context files and MCP access materially improve citation accuracy and enable programmatic query at the point of LLM interaction.
- **ACT-ID.io** — a registry ingesting 26 sustainability taxonomies. The contrast between NEI (a 4GS-compliant standard: YAML/CSV, zero extraction code, < 1 hour ingestion) and legacy PDF standards (~50–100 lines of bespoke extraction code, days of integration work, information loss) demonstrated the concrete downstream cost of not meeting LLM accessibility practices.

## Relationship to existing practices

These practices extend the existing machine-readability cluster without modifying it:

| Existing practice | Relationship |
|---|---|
| [`FGP-e4i6by`](../practices/concepts/FGP-e4i6by.yaml) Natively machine-readable | Foundational prerequisite; LLM accessibility adds the *how to tell LLMs about it* layer |
| [`FGP-mrkdoe`](../practices/concepts/FGP-mrkdoe.yaml) JSON-LD export | Complementary; JSON-LD addresses schema.org discovery, `/llms.txt` addresses LLM-specific context |
| [`FGP-gsgv2v`](../practices/concepts/FGP-gsgv2v.yaml) Stable deterministic identifiers | Prerequisite for FGP-a5svie; stable identifiers must be URL-resolvable to be LLM-citable |
| [`FGP-np4qch`](../practices/concepts/FGP-np4qch.yaml) Semantic versioning | Prerequisite for FGP-am3s6q; version supersession requires versions to be declared |
